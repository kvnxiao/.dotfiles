# Optimize implementation

Use implementation scope with [the shared investigation contract](../optimize/references/investigation.md), [the coordination procedure](../optimize/references/coordinate.md), and [implementation guidance](references/investigation.md).

Default to inexpensive investigation. Honor an explicit `deep` or `mode=deep` request; read [experimental validation](../optimize/references/experiments.md) before running an experiment.

Report consequential architectural opportunities as follow-up work. Keep the detailed investigation within the requested scope.
