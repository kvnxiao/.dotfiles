# Optimize architecture

Use architecture scope with [the shared investigation contract](../optimize/references/investigation.md), [the coordination procedure](../optimize/references/coordinate.md), and [architecture guidance](references/investigation.md).

Default to inexpensive investigation. Honor an explicit `deep` or `mode=deep` request; read [experimental validation](../optimize/references/experiments.md) before running an experiment.

Report independent implementation improvements as follow-up work. Keep the detailed investigation within the requested scope.
