# Public final-design diagram survey

Research date: 2026-10-25. Scope: the 32 question breakdowns linked in Hello Interview's public system-design navigation on this date. Inspect unauthenticated page content and its public diagrams; do not infer gated content.

Sixteen examples expose substantive designs. Fourteen label a figure Final Design. GoPuff and WhatsApp instead require their composite and later scaling figures to be considered together. This survey inspected 19 diagrams across these 16 examples. The notes below are original summaries; do not bundle source diagrams into generated packages.

## Conclusions and limits

Rectangular services, elliptical stores, labeled arrows, replica stacks, and nearby schemas recur. Notation varies: WhatsApp reverses several common shape choices, and diamonds sometimes denote dependencies rather than decisions. The skill therefore defines its own consistent semantic defaults.

Client-facing composites often place a gateway before application services; backend pipelines instead start from queues or streams. Persistent connections use specialized ingress. Most additions address a particular read, write, fan-out, storage, contention, or processing bottleneck. These observations support conditional patterns, not a mandatory infrastructure shopping list.

Use [architecture diagram rules](diagram-patterns.md) for generation. Its workload-specific ingress guidance, diamond-as-decision convention, left-to-right primary flow, and Rough.js rendering are skill conventions. They are not universal claims about Hello Interview's figures. Apply technology documentation and invariant reasoning independently; visual repetition does not establish correctness.

## Ticketmaster comparison

The [Ticketmaster breakdown](https://www.hellointerview.com/learn/system-design/problem-breakdowns/ticketmaster) uses gateway ingress for viewing, search and booking services. Its read-scaling section combines stateless replicas, load balancing and caching. Both ticket booking and hotel reservation separate tolerant browsing from authoritative inventory mutation. The hotel aggregator additionally depends on independent provider authority and contractually delegated inventory.

For this skill, show the ingress explicitly when a public backend is replicated, even if domain modules stay in one deployment. Label it by the selected responsibility or product. The article treats load balancing and gateway routing as distinct responsibilities and does not establish a universal gateway requirement for replication.
